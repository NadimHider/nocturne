# Nocturne documentation

Nocturne is a dark, handheld-first NextUI distribution for the Anbernic RG40XX H. These pages cover installation, controls, configuration, architecture, and validation.

| Document | Contents |
| --- | --- |
| [Installation](INSTALL.md) | Requirements, card layout, update and fresh-install procedures, rollback, and troubleshooting |
| [Controls](CONTROLS.md) | Frontend, Quick Menu, Game Switcher, and in-game shortcuts |
| [Configuration](CONFIGURATION.md) | Settings, palettes, fonts, motion, startup view, and `minuisettings.txt` |
| [Palettes](PALETTES.md) | All 35 dark palettes, 10 Night options for dark rooms, custom files, and contrast validation |
| [Sleep and wake](SLEEP.md) | Screen-off then delayed suspend, failure recovery, radio and audio restoration, and device checks |
| [Architecture](ARCHITECTURE.md) | Boot/runtime diagram, components, shared typography/theme/configuration, sleep flow, and build pipeline |
| [Validation](VALIDATION.md) | Automated checks, binary verification, card checks, device checklist, and release provenance |

## Start here

If Nocturne is already installed, read [Controls](CONTROLS.md) and [Configuration](CONFIGURATION.md). If you are updating from NextUI or setting up a new card, read [Installation](INSTALL.md) first.

The v1.0.3 UI uses the Settings app's 10-point Comfortable default throughout primary
text, with four shared size presets. See the [README screenshots](../README.md#screenshots)
for desktop captures of the game systems, game list, Settings, and Appearance.
